# Learning Resources

This folder tracks external courses, workshops, papers, and references that support the hands-on LLM-from-scratch work in this repository.

The goal is not to duplicate course material. Instead, each resource is used to strengthen specific concepts, connect theory to implementation, and record how it contributes to the learning lab.

## Current Resources

- **Building LLMs to Develop Intuition — Justin Angel**  
  Primary implementation-oriented workshop used for the numbered units in `notes/`, `notebooks/`, and `experiments/`.

- **Stanford CS336: Language Modeling from Scratch — Spring 2026**  
  A complementary, more rigorous course covering the end-to-end language-modeling pipeline, including data, tokenization, model construction, training, systems considerations, scaling, and evaluation.

See `stanford_cs336_spring_2026.md` for how CS336 is being integrated into this learning lab.
