# llm-from-scratch-learning-lab

Hands-on learning lab for building LLM components from scratch: tokenization, embeddings, attention, transformers, training, and evaluation.

## Repository Structure

- `notes/` — conceptual notes and cross-unit connections
- `notebooks/` — hands-on implementations and experiments
- `experiments/` — focused benchmark and analysis write-ups
- `resources/` — external courses, workshops, papers, and references used to deepen the learning path

## Learning Resources

The main numbered learning sequence is implementation-oriented and is complemented by additional academic resources.

Current complementary resource:

- **Stanford CS336: Language Modeling from Scratch — Spring 2026** — an implementation-heavy Stanford course covering tokenization, model construction, systems, scaling, data, evaluation, and alignment. See `resources/stanford_cs336_spring_2026.md`.
